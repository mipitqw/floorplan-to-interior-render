# 提示词配方（Seedream v5.5 · 户型图生装修效果图）

> 硬约束：`prompt` ≤ 600 字符，**中文建议 ≤ 300 字**。目标区间 **250~295 字**——
> 低于 200 字基本都会"空"，超过 300 字模型开始丢细节。
> 没有负面提示词参数，所有"不要"都要写成正向描述。
> 模板里的 `<>` 是槽位；`<风格串>` 直接抄 `style-list.md` 里的"提示词串"（56~68 字）。

---

## 一、五段式结构（必须按这个顺序）

| # | 段落 | 字数 | 作用 |
| --- | --- | --- | --- |
| 1 | 画面类型与机位 | 30~45 | 定构图。放最前面 |
| 2 | 家具主件清单 | 50~70 | 定格局。**带材质和颜色** |
| 3 | **软装与道具**（新增） | 60~80 | **定质感，解决"空"** |
| 4 | 风格串 + 灯光 | 70~90 | 定调性与氛围 |
| 5 | 排除项 | 20~30 | 收尾最有效 |

第 3 段是这次升级的核心。没有它，流程图再准也只是**空房子**。

> 把"无文字"写在第一句 → 模型先丢主体；放最后一句 → 最有效。

## 二、节点 2：鸟瞰顶视图

### 模板 A（标准版，推荐）

```
以这张户型平面图为唯一结构依据，生成该户型的轴测剖切鸟瞰透视图：去掉屋顶与顶棚，45度俯视，四壁与地面完整可见。严格按平面图的墙体走向、房间数量与分隔重建，不改动房间位置、不增删房间。共<N>个空间：<逐个列出 客厅/餐厅/厨房/主卧/次卧/卫生间/阳台 及相对方位>。每个空间家具按功能就位并配齐软装：客厅有地毯、抱枕、边几台灯与绿植，餐厅有桌旗、餐具与吊灯，卧室有床品叠层、床头灯与地毯，卫生间有毛巾、香薰与绿植。<风格串>。纯白背景，户型完整居中、四周留白。画面无任何文字、尺寸线、编号、水印与人物。
```

- `<N>` 和逐个空间名**必须写**。写"还原原图格局"这种笼统话，模型会自己发明房间。
- 鸟瞰也要配软装——空房间的鸟瞰看起来像 CAD 图，一览就假。
- 相对方位用「左侧/右侧/上部/下部/中部」，比方位角好用。

### 模板 B（细节核对版）

```
模板 A 结尾追加：家具与洁具只作示意、形体简洁，重点表达墙体分隔与房间面积比例。
```

出 A、B 两版让用户挑，B 更利于核对格局。

### 鸟瞰特有的坑

| 现象 | 改法 |
| --- | --- |
| 出成 2D 彩色平面图 | 开头改为「三维建筑鸟瞰透视效果图，实景渲染」；删掉"图""示意""平面"这类词 |
| 屋顶没去掉 | 把"去掉屋顶与顶棚"提到第一句，加"开放式剖切、可看到每个房间内部" |
| 房间数不对 | 模板里逐个点名 + 标方位；再不行减少参考图（只给平面图） |
| 背景不是纯白 | 「纯白背景」单独成句，加"无地面投影、无环境配景" |
| 变形、比例被拉扁 | 检查是否用了固定 size；改用 `--size auto` |

## 三、节点 3：分区实景

### 通用模板（五段式）

```
<房间名>室内实景照片。<机位>。<家具主件：材质+颜色+位置>。<软装与道具：3~4 件，材质+颜色+位置>。<风格串>。<灯光三层>。真实摄影质感，透视自然。画面无人物、无文字、无水印。
```

**参考图给谁**：
- 首选 `鸟瞰图` 一张——同时锁住风格、房间比例、家具位置，一致性最好。
- 房间形状特别要紧时，追加 `平面图` 作第二张，提示词里写"按第一张平面图的房间形状取景"。
- **一次不要超过 2 张**。参考图越多，模型越容易串房间。

### 机位 / 主件 / 软装道具对照表

| 空间 | 机位 | 家具主件 | 软装道具（挑 3~4 件） | size |
| --- | --- | --- | --- | --- |
| 客厅 | 站在玄关或过道口望向落地窗，视高 1.3m，广角 | 三人沙发、圆茶几、电视柜、地毯 | 抱枕 3~5、搭毯、托盘+画册+陶杯、大幅挂画、落地灯、大型绿植 | 默认 3:4 |
| 餐厅 | 从客厅侧斜 45° 望向餐桌与餐边柜 | 六人餐桌、餐椅、餐边柜、吊灯 | 亚麻桌旗、叠放陶盘、玻璃杯、花瓶插枝、果盘、蜡烛台 | 默认 3:4 |
| 厨房 | 站门口向内，正对灶台—水槽—冰箱动线 | 橱柜、台面、灶台、水槽、冰箱 | 木砧板、陶罐木勺、调料瓶、皂液瓶、窗边香草小盆栽、柜下灯带 | 默认 3:4 |
| 玄关 | 从室内向入户门 | 鞋柜、换鞋凳、挂衣钩 | 圆镜、托盘钥匙、香薰、地垫、藤编鞋篮、小瓶花、拖鞋 | 默认 3:4 |
| 主卧 | 从门口向内，床偏一侧，能看到窗 | 双人床、两床头柜、衣柜、地毯 | 床品三层+搭毯、抱枕 4~6、床头台灯、书与水杯、双层窗帘 | 默认 3:4 |
| 次卧/书房 | 从门口向内斜拍 | 单人床或书桌、书柜、衣柜 | 台灯、摊开的书、笔筒、小盆栽、洞洞板/层板、编织筐 | 默认 3:4 |
| 卫生间 | 站门口斜 45°，同时看到台盆区与湿区 | 台盆柜、镜柜、马桶、玻璃淋浴房 | 皂液瓶、牙刷杯、小托盘护肤品、毛巾、地垫、耐湿绿植 | 默认 3:4 |
| 阳台 | 从室内客厅向外，落地窗为框 | 洗烘机、洗手台、吊柜、休闲桌椅 | 洗衣篮、收纳罐、坐垫、小边几+杯与书、成组绿植 3~5 盆、晾着的白衬衫 | 默认 3:4 |

> **size 一律留空 = 默认 3:4（1392x1856，258 万像素）。** 上表不写 `--size` 就是这套。
> 只有用户明确要横构图时，才整组改成 `--size 16:9`（2144x1200）；同一套图比例必须统一。
> 横构图时第 1 段的机位句要跟着改（广角、更多横向展开），否则 3:4 的竖构图文字配 16:9 画布会左右空。

### 完整示例（客厅，286 字，可直接改）

```
客厅室内实景照片。站在玄关过道口望向南向落地窗采光面，视高约1.3米，24毫米广角。米白棉麻三人沙发靠左墙，浅橡木圆角茶几居中，右侧浅木电视柜贴墙，米色羊毛地毯压住沙发前脚。沙发上三只抱枕——两只奶白、一只焦糖羊羔绒，灰褐针织搭毯随意搭在扶手；茶几上木质托盘放两本画册、一只粗陶杯和香薰；沙发背景一幅米灰大幅抽象画配细木框，角落一株琴叶榕配米白陶盆。原木奶油风，奶油白哑光墙，浅橡木地板，圆角浅橡木家具，粗陶花器插尤加利，藤编篮点缀，3000K暖光三层照明。南向窗光斜射地面形成柔和光斑，天花暗藏灯带洗墙，落地灯暖光晕笼罩沙发一角。真实摄影质感，透视自然。画面无人物、无文字、无水印。
```

## 四、密度自检（提交前数一遍）

出图前用这 6 条过一遍，任何一条不达标就加料：

- [ ] 能数出**≥7 件具体物件**（不含墙地顶）？
- [ ] 物件分在**三个高度层**（地面 / 台面 / 立面）都有？
- [ ] 写了**≥3 种材质**，且有一种是主材质？
- [ ] 有**且只有 1~2 个点缀色**？
- [ ] 有**三层光**（窗光 / 基础光 / 氛围光）？
- [ ] 有 **1~2 处生活痕迹**（摊开的书、半杯水、搭着的毯子）？

不达标时，优先加这三样（性价比最高）：
**① 地毯 ② 沙发背景大幅画 ③ 落地灯 + 边几上的道具**。

## 五、"空 / 平 / 假"的加料速查

| 症状 | 加什么 |
| --- | --- |
| 空（墙大面空白、地面没东西） | 大地毯 → 大幅挂画 → 落地灯 + 边几道具 → 大型绿植 → 抱枕 3~5 只 |
| 平（有物件没高低） | 高低错落（矮几配高柜、落地灯配台灯）→ 一大一小两幅画 → 材质对比（木+金属+陶）→ 织物垂坠感 |
| 假（像样板间/像 3D） | 生活痕迹（摊开的书、半杯水、拖鞋）→ 三层光影 → 纹理细节（木纹、褶皱、手作痕）→ 轻微不完美（抱枕歪、毯子起皱） |
| 杂（太花） | 砍到 1 个跳色、材质压到 3 种、留白提到 35%、去掉一半摆件 |
| 冷（没人味） | 加暖光（3000K）、加织物（搭毯/地毯/窗帘褶皱）、加木与陶 |

更多逐空间的元件清单见 `styling-library.md` 第三节。

## 六、排除项写法对照

| 想要 | 写成（正向） | 别写 |
| --- | --- | --- |
| 画面干净 | 纯白背景，四周留白，无环境配景 | no background clutter |
| 不要文字 | 画面无任何文字、数字、标注、尺寸线、编号 | no text |
| 不要人 | 空无一人，房间无人 | no people |
| 不要水印 | （接口侧 `watermark: false`，提示词不用提） | — |
| 不要穿模 | 家具形体完整、边界清晰、比例协调 | no floating objects |

## 七、返工提示词怎么改

不要重头重写，**只改一段**，其余原样保留——这样才知道是哪句话起作用了。

| 症状 | 只改这一段 |
| --- | --- |
| 风格不对 | `<风格串>` 换成清单里的标准串，地面/墙面材质写死 |
| 画面空 | **第 3 段软装**：加 2~3 件，全部带材质与位置 |
| 画面太杂 | 第 3 段砍到 3 件，跳色压到 1 个，加"留白充足" |
| 家具位置错 | 第 2 段，用「左墙/右墙/居中/靠窗」明确位置 |
| 视角不对 | 第 1 段机位，改成"人眼平视，视高1.3米，不要俯视" |
| 太像效果图不像照片 | 删掉"效果图""渲染"，加"真实摄影、胶片质感、轻微广角畸变" |
| 出现文字或标签 | 结尾排除句加长 |
| 出成了别的房间 | 参考图只留鸟瞰一张；第 1 段点名房间，第 2 段写死该房间家具 |

## 八、省钱的调试顺序

1. `--validate-only` 查字数、图片路径与**实际尺寸**（零成本，脚本会把每个 job 解析成什么尺寸打出来）。
2. `--print-curl` 看拼出来的真实请求（零成本）。
3. `1280x720`（接口允许的最小像素，最便宜）试构图，对了再按默认 3:4（`1392x1856`）出正稿。
   （`1024x576` 会因总像素 < 921600 被拒，别用。）
4. 一版通过就停手，不要"再出一张更好的"——每张都要花钱。
