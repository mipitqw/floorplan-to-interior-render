# 可选室内风格清单（含配色 / 软装 / 签名单品）

> 单选使用。**每套图只准用一种风格**，鸟瞰、实景、文案共用同一组关键词。
> 每个风格给到：631 配色（带 hex）、材质、家具语言、软装、签名单品、灯光、避坑，
> 以及一句可直接粘进 prompt 的「提示词串」（≈70~90 字，别超，后面还要接场景描述）。
>
> 软装元素怎么挑、怎么塞进 300 字，见 `styling-library.md`。

---

## 1. 原木奶油风
- **定位**：温暖松弛、自然治愈
- **配色**：底 60% 奶油白 `#F3EADF` / 浅橡木 `#D9BE9A`｜主 30% 奶咖 `#C9AE93` / 燕麦 `#E6D8C6`｜点 10% 焦糖 `#B4763F`、鼠尾草绿 `#9AA88B`
- **材质**：浅橡木（主）+ 棉麻 + 羊羔绒/针织 + 粗陶
- **家具**：圆角无锐角的浅橡木家具、包覆感布沙发、矮几、弧形靠背椅
- **软装**：米白棉麻抱枕 3~5 只 + 焦糖羊羔绒 1 只、针织搭毯；莫兰迪抽象画；粗陶花器插尤加利或干枝；藤编收纳篮；蘑菇落地灯、纸灯
- **签名单品**：弧形圆镜、蘑菇落地灯、粗陶花器
- **灯光**：3000~3500K，灯带洗墙 + 筒灯 + 落地灯
- **避坑**：别用纯白（发冷）、别加亮面金属或大理石（破功）
- **提示词串**：`原木奶油风，奶油白哑光墙，浅橡木地板，圆角浅橡木家具，米白棉麻沙发配焦糖羊羔绒抱枕，粗陶花器插尤加利，藤编篮点缀，3000K暖光三层照明`

## 2. 现代简约风
- **定位**：干净利落、秩序感强
- **配色**：底 60% 象牙白 `#F2F2EF` / 浅灰 `#D5D7D8`｜主 30% 中灰 `#9FA3A6` / 黑胡桃 `#5A4436`｜点 10% 哑光黑 `#2B2B2B`、雾蓝 `#7C93A6`
- **材质**：哑光乳胶漆（主）+ 微水泥/浅灰大板 + 布艺 + 拉丝金属（4 种）
- **家具**：直线条、悬空平板柜、无拉手、细腿
- **软装**：灰调低饱和抱枕 2~3、纯色搭毯；一幅大尺寸抽象画或黑白摄影；单枝玻璃花瓶；几何造型纸灯；水泥灰盆绿植
- **签名单品**：细黑框装饰画、线性壁灯、水泥灰花盆
- **灯光**：3500~4000K，磁吸轨道 + 筒灯 + 灯带
- **避坑**：别堆多种装饰小物（会变杂）；留白要比别的风格多
- **提示词串**：`现代简约风，象牙白哑光墙面，浅灰大板地砖，无拉手平板柜体，中灰布艺沙发，细黑框抽象画，单枝玻璃花器，轨道灯均匀照明，大面积留白`

## 3. 现代轻奢风
- **定位**：低调精致、品质感
- **配色**：底 60% 暖米白 `#F0E9E1` / 暖灰 `#C9C2B9`｜主 30% 深咖 `#6B5142` / 胡桃 `#7A5642`｜点 10% 香槟金 `#C8A96A`、墨绿 `#33544A`
- **材质**：浅灰大理石纹砖（主）+ 护墙板 + 丝绒/皮质 + 黄铜（4 种）
- **家具**：精致直线条，软包/皮质配金属脚，玻璃台面
- **软装**：丝绒抱枕 2~3、咖灰系皮草搭毯；抽象或极简线条画；黄铜/大理石托盘；蝴蝶兰或鹤望兰；水晶或金属线条吊灯
- **签名单品**：黄铜壁灯、丝绒单椅、大理石托盘
- **灯光**：3000K，分层射灯 + 灯带 + 金属壁灯
- **避坑**：金属是**点缀**不是满屋金属；金要哑光香槟，不要发黄
- **提示词串**：`现代轻奢风，暖灰护墙板配香槟金属收边，浅灰大理石纹地砖，皮质软包沙发配丝绒抱枕，黄铜壁灯，大理石托盘摆香薰，3000K分层射灯`

## 4. 侘寂风
- **定位**：质朴留白、岁月质感
- **配色**：底 60% 米灰 `#DED8CE` / 微水泥 `#C6BFB4`｜主 30% 燕麦 `#CDBFA9` / 灰褐 `#8E8378`｜点 10% 陶土 `#A9765B`、炭黑 `#3A3A38`
- **材质**：微水泥艺术涂料（主）+ 老木 + 亚麻粗麻 + 无釉粗陶（4 种）
- **家具**：低矮、厚实、带手作感，原木不封边
- **软装**：亚麻抱枕 2~3、粗麻搭毯；无框或细木框画（可不挂）；粗陶大罐插枯枝或干芦苇；剑麻地毯；手作陶器成组；纸灯
- **签名单品**：粗陶大罐、纸质落地灯、枯枝
- **灯光**：2700~3000K，低照度、间接灯带、见光不见灯
- **避坑**：物件**宁少勿多**，多一件就变"自然风"；别用亮面瓷砖
- **提示词串**：`侘寂风，米灰微水泥墙面带手抹肌理，剑麻地毯，低矮原木家具，亚麻抱枕与粗麻搭毯，粗陶大罐插枯枝，纸灯漫射暖光，大面积留白`

## 5. 日式风
- **定位**：极简收纳、禅意通透
- **配色**：底 60% 米白 `#F2EDE4` / 浅木 `#DCC9A8`｜主 30% 原木 `#C09A6B` / 浅灰 `#CFCFC9`｜点 10% 苔绿 `#7C8A6B`、墨 `#33383A`
- **材质**：浅木（主）+ 和纸 + 棉麻 + 竹藤（4 种）
- **家具**：低矮原木、推拉门、障子门、格栅
- **软装**：素色棉麻抱枕 2、折叠整齐的薄被；小幅水墨或留白画；素烧陶盘成组；文竹/苔藓球；和纸灯、竹帘
- **签名单品**：和纸灯、素烧陶盘、竹帘
- **灯光**：3000~3500K，暖白柔光，低位照明
- **避坑**：别堆装饰（日式靠"空"），收纳必须藏起来
- **提示词串**：`日式风，米白墙面，浅木地板，低矮原木家具与格栅推拉门，素色棉麻抱枕，素烧陶盘与文竹，和纸灯暖白柔光，收纳规整留白`

## 6. 北欧风
- **定位**：明亮清爽、功能主义
- **配色**：底 60% 纯白 `#F7F7F5` / 浅木 `#E0D2BA`｜主 30% 浅灰 `#D3D5D4` / 雾蓝 `#A8BFC9`｜点 10% 姜黄 `#D9A33B`、砖红 `#B95C4B`
- **材质**：浅木（主）+ 羊毛 + 棉麻 + 白陶（4 种）
- **家具**：浅木 + 白板式、细腿椅、几何造型
- **软装**：几何图案抱枕 3~4、羊毛毯；植物海报或简约挂画（2~3 幅错落）；白陶盆种琴叶榕/绿萝；藤编篮；纸质或藤编吊灯
- **签名单品**：藤编吊灯、羊毛毯、白陶花盆
- **灯光**：4000K + 大面自然光，简洁吊灯 + 工作灯
- **避坑**：别用重色家具；跳色只留一个（姜黄或砖红）
- **提示词串**：`北欧风，纯白墙面与浅木地板，浅木细腿家具，几何图案抱枕与羊毛毯，植物海报挂画，藤编吊灯，白陶盆琴叶榕，大面自然光明亮通透`

## 7. 中古风
- **定位**：复古温暖、线条经典
- **配色**：底 60% 米色 `#EADFCE`（浅墙）｜主 30% 胡桃木 `#6B4A34` / 深棕 `#4A3527`｜点 10% 复古绿 `#3E5646`、芥末黄 `#C39B3E`、砖红 `#A44A3F`
- **材质**：胡桃木（主）+ 真皮/丝绒 + 藤编 + 黄铜（4 种）
- **家具**：圆润曲线、锥形腿、低矮宽大，伊姆斯椅/郁金香椅类单椅
- **软装**：墨绿丝绒或焦糖皮抱枕、灯芯绒/羊羔绒搭毯；几何/植物/复古风景画配胡桃木或黄铜框；钓鱼灯、黄铜球台灯；龟背竹配陶土盆；复古纹理地毯
- **签名单品**：钓鱼灯、胡桃木边柜、复古绿丝绒单椅
- **灯光**：3500K，无主灯 + 落地灯/台灯为主
- **避坑**：别用高饱和亮色；别全屋新家具（要有一两件"旧感"单品）
- **提示词串**：`中古风，米色墙面配胡桃木地板，胡桃木边柜与锥形腿家具，复古绿丝绒单椅，灯芯绒抱枕与羊毛地毯，钓鱼灯黄铜台灯，龟背竹陶土盆，3500K暖光`

## 8. 法式风
- **定位**：优雅浪漫、线条精致
- **配色**：底 60% 奶白 `#F5F0E8` / 浅灰 `#D9D6D1`｜主 30% 雾霾蓝 `#9AAEB8` / 浅木 `#D8C2A3`｜点 10% 香槟金 `#C2A05B`、藕粉 `#C9A6A0`
- **材质**：人字拼木地板（主）+ 石膏线/护墙板 + 丝绒/蕾丝 + 黄铜（4 种）
- **家具**：弧形靠背、细高脚、描金边、软包
- **软装**：丝绒抱枕 2~3 + 提花靠垫 1；油画或复古镜（对称成组挂）；水晶/黄铜吊灯 + 对称壁灯；绣球/尤加利插白瓷瓶；蕾丝桌布、烛台
- **签名单品**：石膏线框装饰镜、黄铜吊灯、丝绒抱枕
- **灯光**：3000K，吊灯为焦点 + 对称壁灯 + 烛台
- **避坑**：图案种类 ≤2 种；别用亮金 + 大红（会俗）
- **提示词串**：`法式风，人字拼木地板，奶白墙面石膏线与细护墙板，弧形细高脚家具配丝绒抱枕，对称黄铜壁灯与吊灯，绣球插白瓷瓶，蕾丝与烛台，3000K暖光`

## 9. 美式风
- **定位**：大气稳重、舒适实用
- **配色**：底 60% 米白 `#EFE6D8` / 卡其 `#C9B79B`｜主 30% 深胡桃 `#5A3E2B` / 墨绿 `#3B4E42`｜点 10% 酒红 `#7A2E33`、黄铜 `#B08D57`
- **材质**：深色实木（主）+ 真皮 + 格纹布 + 铜器（4 种）
- **家具**：实木大件、厚重茶几、卷边皮沙发、带铆钉细节
- **软装**：格纹/条纹抱枕 3~4、羊毛毯；风景或静物油画配深木框；铜质托盘、老式台灯；散尾葵或橡皮树；壁炉 + 柴火堆
- **签名单品**：黄铜台灯、格纹抱枕、铜质托盘
- **灯光**：2700~3000K，吊灯 + 台灯 + 壁炉火光
- **避坑**：别用北欧那种细腿（撑不住美式的份量）；深色占大面积会闷
- **提示词串**：`美式风，米白墙面与深色实木地板，实木大件家具与深色皮沙发，格纹抱枕与羊毛毯，黄铜台灯与铜质托盘，散尾葵，壁炉火光，2700K暖光`

## 10. 新中式
- **定位**：东方雅致、现代传承
- **配色**：底 60% 米白 `#F2EDE5` / 浅灰 `#D6D3CC`｜主 30% 胡桃 `#5C4433` / 墨黑 `#2E2E2C`｜点 10% 青瓷绿 `#8FA79B`、赭石 `#A0653F`
- **材质**：黑胡桃木（主）+ 硬包/木格栅 + 棉麻 + 青瓷（4 种）
- **家具**：细腿、线条利落、少雕花、改良圈椅、禅意茶台
- **软装**：素色棉麻抱枕 2、亚麻搭毯；水墨/山水极简画或卷轴（宁可只有一幅）；青瓷花器插松枝或南天竹；紫砂茶具；木格栅屏风、灯笼造型壁灯
- **签名单品**：青瓷花器、水墨挂画、木格栅屏风
- **灯光**：3500K，无主灯 + 洗墙 + 灯笼壁灯
- **避坑**：**别满屋中式符号**（格栅+雕花+回纹一起上 = 老气）；深木面积别过大
- **提示词串**：`新中式，米白墙面与深色木地板，细腿黑胡桃木家具，素色棉麻抱枕，水墨极简挂画，青瓷花器插松枝，木格栅局部，3500K无主灯洗墙，留白意境`

## 11. 宋式美学
- **定位**：清雅简素、文人意境
- **配色**：底 60% 牙白 `#F4F0E6` / 浅茶 `#DCD0BC`｜主 30% 墨灰 `#6E6E68` / 原木 `#C4A981`｜点 10% 淡青 `#9FB6AE`、朱砂 `#A9503C`（极少量）
- **材质**：浅木（主）+ 素色砖 + 亚麻 + 青瓷（4 种）
- **家具**：细腿、低重心、线条利落、宋式简约木作
- **软装**：亚麻抱枕 1~2、蒲团；水墨卷轴、书法小画；青瓷浅盘插一枝、菖蒲或兰花；香炉；纸灯、木格灯
- **签名单品**：青瓷浅盘、纸灯、卷轴
- **灯光**：3000~3500K，柔和漫射、低照度
- **避坑**：物件超过 5 件就不"宋"了；别用金、别用亮光
- **提示词串**：`宋式美学，牙白墙面与浅木地板，细腿低重心木作，亚麻抱枕与蒲团，青瓷浅盘插一枝菖蒲，水墨卷轴，纸灯柔和漫射光，疏朗留白`

## 12. 意式极简
- **定位**：高级克制、材质为先
- **配色**：底 60% 灰白 `#E7E5E1` / 暖灰 `#C3BFB8`｜主 30% 炭黑 `#3A3A3A` / 深棕 `#4E3C30`｜点 10% 哑光金属 `#8B8578`、焦糖皮 `#9A5F35`
- **材质**：微水泥/大板石纹（主）+ 真皮 + 羊绒 + 哑光金属（4 种）
- **家具**：低矮大块面、真皮、隐藏收纳、悬浮感
- **软装**：真皮/羊绒单椅 1~2、纯色羊绒搭毯；一幅超大抽象画（或干脆不挂）；细口陶瓶插单枝；每处摆件 ≤2 件
- **签名单品**：哑光黑落地灯、大块面皮沙发、细口陶瓶
- **灯光**：3000~3500K，磁吸轨道 + 洗墙灯带 + 隐藏地脚灯
- **避坑**：**克制**是核心，多一件小物就掉档；别用花纹
- **提示词串**：`意式极简，灰白微水泥墙面，大规格石纹地砖，低矮大块面真皮沙发，羊绒搭毯，细口陶瓶插单枝，哑光黑落地灯，磁吸轨道无主灯，极简克制`

## 13. 极简黑白灰
- **定位**：纯粹利落、强对比
- **配色**：底 60% 白 `#F5F5F5` / 浅灰 `#D8D8D8`｜主 30% 深灰 `#6E6E6E` / 黑 `#1F1F1F`｜点 10% 木色缓冲 `#C0A47E`
- **材质**：哑光乳胶漆（主）+ 浅灰大砖 + 灰布艺 + 黑金属（4 种）
- **家具**：几何块面、平板无拉手、黑色金属件
- **软装**：灰黑纯色抱枕 2~3、灰色搭毯；黑白摄影或几何版画（1~2 幅）；黑色金属边几；虎皮兰黑盆；几何纸灯
- **签名单品**：黑色金属边几、几何纸灯、黑白摄影
- **灯光**：3500~4000K，线性灯 + 筒灯，明暗对比清晰
- **避坑**：必须留一点木色或绿植缓冲，否则像办公室
- **提示词串**：`极简黑白灰，白与浅灰分色墙面，浅灰大板地砖，几何块面平板柜体黑色金属件，灰黑纯色抱枕，黑白摄影挂画，虎皮兰黑盆，线性灯清晰明暗`

## 14. 复古南洋风
- **定位**：热带复古、休闲厚重
- **配色**：底 60% 米黄 `#EFE0BC` / 奶白 `#F2EAD9`｜主 30% 深木 `#5A3A26` / 墨绿 `#2F4A3C`｜点 10% 砖红 `#A8503C`、焦糖 `#B87A3E`
- **材质**：深木（主）+ 花砖 + 藤编 + 棉麻（4 种）
- **家具**：藤编 + 实木混搭、弧形、低矮
- **软装**：棉麻或印花抱枕 3~4、藤编靠垫；热带植物挂画或老照片墙；天堂鸟/散尾葵成组；藤编吊扇灯、黄铜壁灯；花砖托盘、藤篮
- **签名单品**：藤编吊扇灯、花砖托盘、藤编篮
- **灯光**：2700~3000K，吊扇灯 + 壁灯 + 串灯
- **避坑**：绿植别太多（会变丛林）；花砖只用局部，别通铺
- **提示词串**：`复古南洋风，米黄墙面与深色木地板，藤编实木弧形家具，印花棉麻抱枕，天堂鸟与散尾葵，藤编吊扇灯，花砖托盘，2700K暖光，慵懒度假感`

## 15. 轻法式奶油
- **定位**：法式线条 + 奶油底色
- **配色**：底 60% 奶白 `#F6F0E6` / 浅米 `#EDE0CE`｜主 30% 浅木 `#D8C2A3` / 浅灰 `#D3D0CB`｜点 10% 浅金 `#C9AC7A`、粉蓝 `#A9BFCB`
- **材质**：浅色人字拼木（主）+ 石膏线 + 亚麻/蕾丝 + 小黄铜（4 种）
- **家具**：弧形浅木或白家具、细腿柜、软包沙发、圆角
- **软装**：亚麻抱枕 2~3 + 蕾丝靠垫 1；小幅油画或镜面装饰（成对）；绣球/尤加利插白陶瓶；小花束、蜡烛；小黄铜吊灯/壁灯
- **签名单品**：石膏线装饰镜、小黄铜吊灯、蕾丝靠垫
- **灯光**：3000K，暖柔光，低位多点
- **避坑**：别做成"重法式"（描金+水晶+雕花一起上会腻）；粉蓝只能做点缀
- **提示词串**：`轻法式奶油风，浅色人字拼地板，奶白墙面石膏线细护墙板，弧形浅木家具与亚麻软包沙发，蕾丝靠垫，绣球插白陶瓶，小黄铜吊灯，3000K暖柔光`

## 选用规则

1. 用户指定了就照做，不要自作主张换风格。
2. 用户没说 → 只问一次，把上面 15 个名字报给他单选（**不要**擅自推荐）。
3. 用户说"介于 A 和 B 之间" → 先定主风格，另一种**只取点缀色**，家具语言必须服从主风格。
4. 同一套图内出现两套核心配色 = 废片，整组重出。
5. 风格关键词**只控制视觉表达**，不允许改变房间数量、功能、墙体位置。
6. 同一套图的每个房间，**签名单品至少重复出现 2 件**——这是成套感的来源。
