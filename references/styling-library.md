# 软装与配饰元件库

> 这份文件解决一个问题：**出图为什么空**。
> 答案通常不是模型不行，是提示词里只有"沙发""地板""墙面"三个大件，
> 没有小件、没有材质肌理、没有光源、没有生活痕迹。
>
> 用法：写提示词时从第二节"道具库"和 `style-list.md` 的"签名单品"里挑 5~8 件塞进去。

---

## 一、画面为什么会"空"——三个根因

| 根因 | 表现 | 对症 |
| --- | --- | --- |
| 只有大件 | 一张图里能数出来的物件 ≤4 件 | 加**台面道具**（托盘/书/杯/蜡烛）+ **地面织物**（地毯/地垫）+ **立面装饰**（挂画/壁灯/搁板） |
| 只有颜色名 | "米白色墙面""浅木地板"，画面平 | 颜色后面跟**材质肌理**（哑光乳胶漆、浅橡木凹凸木纹、亚麻粗织纹） |
| 没有人的痕迹 | 像空置样板间 | 加**生活痕迹**：摊开的画册、半杯水、搭在扶手的毯子、拖鞋、切开的柠檬、挂着的围裙 |

一句话：**大件定格局，小件定质感，痕迹定真实。**

## 二、八条丰富度法则（每张图都过一遍）

### 1. 631 配色，不许自由发挥
- **60% 底色**：墙、地、天花、大面积柜体 → 只许一个色系
- **30% 主角色**：沙发、床、窗帘、地毯 → 同色系深浅变化
- **10% 点缀色**：抱枕、挂画、花瓶、单椅 → **1~2 个跳色，最多 2 个**

> 点缀色超过 2 个，画面立刻变杂牌展厅。宁可少，不可多。

### 2. 材质 3~5 种，且有主次
全屋同一材质 = 平；材质超过 5 种 = 乱。标准配比是
**1 主材质（木/微水泥/石材）+ 2 软材质（棉麻/绒/羊毛）+ 1 硬点缀（金属/玻璃/陶）**。

### 3. 三段层次，视线由低到高
| 层 | 高度 | 放什么 |
| --- | --- | --- |
| 低 | 0~40cm | 地毯、地垫、蒲团、藤篮、绿植盆 |
| 中 | 40~110cm | 沙发、茶几、边几、单椅、落地灯、矮柜台面道具 |
| 高 | 110cm+ | 挂画、壁灯、吊灯、搁板、高柜、大型绿植 |

**只写中段，画面必然空。** 三段都要有物件。

### 4. 一个视觉焦点，其余退后
每张图指定**唯一焦点**：沙发背景大幅抽象画 / 特色电视墙 / 造型吊灯 / 壁炉 / 落地窗景。
焦点之外的家具"颜色更浅、造型更简"，用"其余家具退后、颜色更浅"这种话压住。

### 5. 道具 ≥5 件，且分三处摆
5 件不是堆一起，是分散在**茶几、边几/矮柜、地面**三处：
- 茶几：托盘 + 精装画册 2 本 + 粗陶杯 + 小香薰
- 边几/矮柜：陶瓶插干枝 + 藤编小篮 + 台灯
- 地面：地毯 + 藤篮装毯 + 大型绿植

### 6. 光影三层，别只写"柔和暖光"
| 层 | 写法示例 |
| --- | --- |
| 自然光 | 南向窗光斜射、纱帘透光、地面有柔和光斑 |
| 基础光 | 天花暗藏灯带洗墙、筒灯均匀洒落 |
| 氛围光 | 落地灯暖光晕、台灯照亮台面局部、蜡烛微光 |

三层光同时出现，画质立刻从"效果图"变"摄影"。

### 7. 签名单品 2~3 件，跨图重复
同一套图的每个房间都出现**同样的 2~3 件小物**（例：奶油风=圆镜+蘑菇落地灯+粗陶花器；
中古风=钓鱼灯+胡桃木边柜+复古绿丝绒单椅）。
这是成套感的来源，比"保持风格一致"这种抽象要求有效得多。

### 8. 留白 25~35%
堆满 = 廉价。提示词里明确写"留白充足、墙面大面积留白、勿堆砌"。
**丰富 ≠ 拥挤**：物件多但每件周围有呼吸空间。

## 四、材质对照（选 3~5 种，1 主 2 软 1 硬）

| 类型 | 材料 | 触感/气质 |
| --- | --- | --- |
| 主·木 | 浅橡木、白蜡木、胡桃木、柚木、樱桃木 | 温润，定基调 |
| 主·石/灰 | 微水泥、艺术涂料、哑光大理石、水磨石 | 冷峻或质朴 |
| 软·布 | 棉麻、亚麻、雪尼尔、灯芯绒、羊羔绒、丝绒 | 决定温度 |
| 软·织 | 羊毛地毯、剑麻、粗针织毯、针织靠垫 | 决定层次 |
| 硬·点缀 | 黄铜、拉丝不锈钢、黑铁、玻璃、镜面、亚克力 | 提亮、加精致度 |
| 自然 | 藤编、竹、草编、原木树桩、陶土、石材 | 加松弛感 |

## 七、"空 / 平 / 假"三症状的加法速查

| 症状 | 一眼能看出的问题 | 加什么（按性价比排序） |
| --- | --- | --- |
| **空** | 墙面大片留白、地面没东西 | ① 大地毯（沙发前脚压上）② 沙发背景大幅画 ③ 落地灯 + 边几 ④ 大型绿植 ⑤ 抱枕 3~5 个 |
| **平** | 有物件但都一个样，没高低 | ① 高低错落（矮几配高柜、落地灯配台灯）② 一大一小两幅画错落 ③ 材料对比（木 + 金属 + 陶）④ 织物垂坠感（搭毯、窗帘褶皱） |
| **假** | 像样板间/像 3D 渲染 | ① 生活痕迹（摊开的书、半杯水、搭着的毯子、拖鞋）② 光影（窗光光斑 + 灯带洗墙 + 蜡烛）③ 纹理细节（木纹、织物褶皱、陶器手作痕）④ 轻微不完美（抱枕歪斜、毯子起皱） |
| **杂** | 东西太多颜色太花 | 反向操作：砍到 1 个跳色、材质压到 3 种、留白提到 35% |

## 八、提示词里的"高密度写法"

同样的字数，写出更多信息。公式：**材质 + 颜色 + 物件 + 位置**。

| 低密度 | 高密度 |
| --- | --- |
| 茶几上放着东西 | 浅橡木圆茶几上放木质托盘、两本精装画册与一只粗陶杯 |
| 有抱枕 | 米白棉麻沙发上三只抱枕，两只奶白一只焦糖色羊羔绒 |
| 有画 | 沙发背景一幅米灰色大幅抽象画，细木框 |
| 有灯 | 沙发旁弧形落地灯，暖光晕打在墙面与地毯上 |
| 有绿植 | 角落一株琴叶榕，米白陶盆，高约一人高 |

**每次落笔前问自己三句**：这几件东西**具体是什么**？**什么材质**？**在哪里**？
