# 节点审批核对清单

> 每个节点出图后逐项核对；不通过先判断"局部还是整体"，再返工。
> **通过并经用户明确选定一版之后**，才允许进入下一节点。

---

## 节点 0：接单

- [ ] **逐轮询问**：先图 → 再风格 → 再范围与特殊要求，**一轮只问一件**，没有一次性甩清单
- [ ] 尺寸已说明（默认 3:4 / 258 万），用户不表态即按默认，没追问第二遍
- [ ] 户型平面图已拿到，能打开、字和尺寸看得清（看不清的先让用户重拍/换原图）
- [ ] 风格已确定（用户指定，或用户从 15 个风格里选了 1 个）
- [ ] 出图范围已确认（默认全部房间 + 阳台）
- [ ] 特殊要求已记录（阳台分区、衣帽间、柜体、宠物位等）
- [ ] 缺信息（朝向、层高、承重墙、梁柱）已列进"待核实清单"，**没有编造**

---

## 节点 1：户型参数拆解（文字 + 编号标注图）

- [ ] 室 / 厅 / 卫数量与原图一致
- [ ] 每个空间有编号、名称、方位，无错配
- [ ] 主卧、公卫、公共区（客餐厅）的位置说对了
- [ ] 墙体走向、门洞位置与开启方向、窗位置与原图对得上
- [ ] 电梯井 / 管井标注为"非室内空间"，没被当成房间
- [ ] 图面直读尺寸 与 反推参考尺寸 分开写，反推值都标了"参考，非施工图"
- [ ] 待核实清单完整：内部净尺寸、墙厚、层高、梁柱、朝向、洞口宽高
- [ ] 标注副本图（`annotate_plan.py` 产物）编号可读、与分区表一一对应
- [ ] **用户已确认分区编号与方位**
- [ ] **已 present_files 推送标注图 + 拆解表**（推了才算交付，只写路径不算）

---

## 节点 2：鸟瞰顶视图

- [ ] 画布比例 = 户型图比例（用了 `--size auto`）
- [ ] 视角统一：45° 轴测俯视、去屋顶、四壁完整
- [ ] 房间数量正确，无增删、无错配、无凭空多出来的房间
- [ ] 外墙轮廓、内墙分隔、门洞、窗位、井道凸出块 与原图一致（能对上的项越多越好）
- [ ] 风格与选定风格一致（拿 `style-list.md` 的提示词串逐项对）
- [ ] 纯白背景、户型完整居中、四周留白
- [ ] 画面无文字、标注、尺寸线、编号、水印、人物
- [ ] **用户已从多版中选定一版**
- [ ] **鸟瞰 A/B 已推送**（拼 `_总览.png` 并排对比更好选）

> 参考生图不是结构控制，个别墙体对不齐属正常。判断标准：**房间数量、功能归属、
> 主卧方位、公共区位置**四项必须对；细节墙体可有偏差，但要在交付说明里点出来。
> 如果四项里有 2 项以上错 → 整节点重出，别修。

## 节点 3：分区实景

### 开工前
- [ ] **出图路线已让用户选**（A 先主空间 / B 一次全出），**没有替用户默认**
- [ ] 路线 A：主空间已推送并拿到用户确认，才批量出剩余房间
- [ ] 路线 B：已告知"组间不停、出完统一看"，用户同意

### 公共区
- [ ] 客厅：采光面方向对，沙发/茶几/电视柜按分区表就位
- [ ] 餐厅：餐桌椅数量对（默认六人位）、餐边柜在墙边、与厨房连通方式对
- [ ] 厨房：洗—切—炒动线顺，灶台/水槽/冰箱位与原图一致
- [ ] 玄关：入户门方向对，鞋柜/换鞋凳位置合理

### 卧室
- [ ] 床向、床头柜、衣柜位置与分区表一致
- [ ] 采光窗方向对；主卧套间能看出衣帽间 / 主卫关系
- [ ] 书房 / 次卧按示意布置，功能不混淆（别把书房画成客房）

### 卫生间
- [ ] 马桶、台盆、淋浴/浴缸位置与原图对应
- [ ] 洁具风格服从主风格；干湿分区表达清楚
- [ ] 镜面 / 墙面 / 柜体上**没有任何文字、logo、数字**

### 阳台
- [ ] 洗烘区与休闲区左右分区明确，互不遮挡
- [ ] 洗烘机位、吊柜/晾衣杆、台盆收纳齐全；休闲桌椅与绿植到位
- [ ] 与客厅落地窗衔接自然
- [ ] 方案设想部分（原图没有阳台时）已在文案/交付里注明"待现场核实"

### 全组通用
- [ ] **画面不空**：每张能数出 ≥7 件具体物件（不含墙、地、顶）
- [ ] **三层高度都有东西**：地面（地毯/地垫/藤篮）、台面（托盘/书/杯/花器）、立面（挂画/壁灯/搁板）
- [ ] **≥3 种材质**，且能看出主材质（木 / 微水泥 / 石材）
- [ ] **点缀色 ≤2 个**，其余都是同色系深浅
- [ ] **三层光**：窗光/自然光 + 灯带或筒灯 + 落地灯/台灯/蜡烛
- [ ] **1~2 处生活痕迹**：摊开的书、半杯水、搭着的毯子、拖鞋、切开的柠檬
- [ ] 该风格的**签名单品至少出现 2 件**，且跨房间重复（见 `style-list.md`）
- [ ] 同一套图 size 统一：**默认全组 3:4（1392x1856）**；明确要横构图时全组 `16:9`（2144x1200）
- [ ] 每张总像素 **≤260 万**（没有 `--allow-big` 的前提下；`--validate-only` 会打印实际尺寸，扫一眼）
- [ ] 配色、材质、家具语言组内一致，与鸟瞰版一致
- [ ] 机位符合空间功能；透视合理，无穿模、无比例失真
- [ ] 无人物、无文字水印
- [ ] 单房有瑕疵时**只重出该房**，不牵连同组已定稿
- [ ] **本组已拼总览并推送**：`contact_sheet.py` → `_总览.png` 在前、原图在后
- [ ] 返工过的单张已**重拼一次总览**再推送（别让用户看旧总览）

## 常见瑕疵 → 返工方式

| 瑕疵 | 表现 | 怎么修 |
| --- | --- | --- |
| **画面空** | 墙大面空白、地面没东西、像空置房 | 按 `styling-library.md` 第八节补：先加地毯 → 大幅挂画 → 落地灯+边几道具 → 大型绿植 → 抱枕 3~5 |
| **画面平** | 有物件但都在同一高度、同一种材质 | 加高低错落（矮几配高柜）→ 加材质对比（木+金属+陶）→ 加织物垂坠（搭毯、窗帘褶皱） |
| **画面假** | 像样板间、像 3D 渲染 | 加生活痕迹 + 三层光影 + 纹理细节（木纹/褶皱/手作痕） |
| **画面杂** | 东西太多、颜色太花 | 反向操作：跳色砍到 1 个、材质压到 3 种、摆件去掉一半、加"留白充足" |
| 格局偏差 | 房间数错、主卧方位错、井道画成房间 | 整节点重出，提示词逐个点名房间 + 方位 |
| 风格跑偏 | 配色/材质/家具与选定风格不符 | 换标准"提示词串"，把地面墙面材质写死，整组重出 |
| 局部瑕疵 | 单房家具错位、洁具位置错、穿模 | 只重出该房，参考图与提示词其余部分不变 |
| 文字混入 | 镜面/墙面/柜体出现字样、编号、水印 | 重出该张，结尾排除句加长 |
| 视角乱 | 各房间机位/比例差异大 | 统一机位规则（见 prompt-recipes 机位表）后整组重出 |
| 比例不齐 | 有的横有的方，拼起来不齐 | 检查是不是混用了 `2K` 档位；一律改显式 WxH |
| 成套感弱 | 每张都好看，但不像一套 | 检查签名单品是否跨图重复；统一跳色与画框材质 |
| 出成平面图 | 鸟瞰变成了 2D 色块图 | 开头改成"三维建筑鸟瞰透视效果图、实景渲染" |
| 尺寸臆造 | 文案或画面写出未核实开间/面积 | 删掉数字，改成"参考描述"，列入待核实 |
| 402 报错 | 接口返回 `401007` | 不是提示词问题，去控制台开通后付费 |
